# MyLife
MyLife is a personal life management platform designed to organize memories, diary entries, goals, habits, and personal insights.

## Technology Stack

### Frontend
- Angular
- TypeScript
- SCSS

### Backend
- .NET 10 Web API
- Entity Framework Core

### Database
- SQL Server

## Planned Features

- Diary Management
- Authentication
- Goal Tracking
- Habit Tracking
- Mood Tracking
- Timeline
- Dashboard Analytics
- Search
